# Cấu hình và Tùy chỉnh Claude Code

## Tổng quan hệ thống cấu hình

Claude Code có hệ thống cấu hình nhiều lớp, cho phép tùy chỉnh từ mức global (user) đến mức dự án cụ thể. Hiểu rõ các lớp cấu hình giúp bạn thiết lập môi trường làm việc tối ưu.

## Settings File

### Global Settings

File `~/.claude/settings.json` chứa cấu hình áp dụng cho tất cả dự án:

```json
{
  "model": "claude-sonnet-4-6",
  "permissions": {
    "allow": [
      "Bash(npm run *)",
      "Bash(git *)",
      "Bash(npx prettier *)",
      "Read",
      "Glob",
      "Grep"
    ],
    "deny": [
      "Bash(rm -rf *)",
      "Bash(sudo *)"
    ]
  },
  "mcpServers": {
    "memory": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-memory"]
    }
  },
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit",
        "command": "npx prettier --write $FILE_PATH"
      }
    ]
  }
}
```

### Project Settings

File `.claude/settings.json` tại root dự án, được ưu tiên hơn global settings:

```json
{
  "permissions": {
    "allow": [
      "Bash(npm run test*)",
      "Bash(npm run lint*)",
      "Bash(npm run build)",
      "Bash(npx prisma *)"
    ]
  },
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "postgresql://localhost:5432/devdb"
      }
    }
  }
}
```

<Callout type="tip" title="Thứ tự ưu tiên">
Khi có xung đột, cấu hình cấp dự án ghi đè cấu hình global. Permissions tuân theo nguyên tắc: deny luôn được ưu tiên hơn allow. Nếu một lệnh match cả allow và deny, nó sẽ bị chặn.
</Callout>

### Cấu hình Permissions chi tiết

Hệ thống permissions cho phép bạn kiểm soát chính xác những gì Claude Code được phép làm:

```json
{
  "permissions": {
    "allow": [
      "Read",
      "Glob",
      "Grep",
      "Bash(npm run *)",
      "Bash(git status)",
      "Bash(git diff*)",
      "Bash(git log*)",
      "Bash(git add *)",
      "Bash(git commit *)",
      "Bash(ls *)",
      "Bash(cat *)",
      "Edit",
      "Write"
    ],
    "deny": [
      "Bash(rm -rf *)",
      "Bash(git push --force*)",
      "Bash(git reset --hard*)",
      "Bash(sudo *)",
      "Bash(chmod 777 *)",
      "Bash(curl * | bash)",
      "Bash(wget * | bash)"
    ]
  }
}
```

## CLAUDE.md - Memory File

`CLAUDE.md` là file quan trọng nhất để tùy chỉnh hành vi của Claude Code. Nó hoạt động như **system prompt bổ sung**, cung cấp context về dự án mà Claude Code sẽ tự động đọc khi khởi chạy.

### Các vị trí CLAUDE.md

Claude Code đọc CLAUDE.md từ nhiều vị trí, mỗi vị trí có phạm vi áp dụng khác nhau:

```
~/CLAUDE.md                    # Global - áp dụng mọi dự án
./CLAUDE.md                    # Project root - toàn bộ dự án
./src/CLAUDE.md                # Directory - chỉ khi làm việc trong src/
./src/components/CLAUDE.md     # Subdirectory - component-specific context
```

### Ví dụ CLAUDE.md cho dự án thực tế

```markdown
<!-- CLAUDE.md tại project root -->

# Project: E-Commerce Platform

## Tech Stack
- Framework: Next.js 15 (App Router)
- Language: TypeScript 5.6 (strict mode)
- Database: PostgreSQL via Prisma ORM
- Auth: NextAuth.js v5
- Styling: Tailwind CSS v4
- Testing: Vitest + Playwright
- Package Manager: pnpm

## Project Structure
- `src/app/` - Next.js app router pages
- `src/components/` - Reusable UI components
- `src/lib/` - Utility functions and shared logic
- `src/server/` - Server-side code (API, DB queries)
- `prisma/` - Database schema and migrations

## Coding Conventions

### Naming
- Files: kebab-case (e.g., `user-profile.tsx`)
- Components: PascalCase (e.g., `UserProfile`)
- Functions: camelCase (e.g., `getUserById`)
- Constants: UPPER_SNAKE_CASE (e.g., `MAX_RETRY_COUNT`)
- Database tables: snake_case (e.g., `user_orders`)

### Patterns
- Server Components by default, "use client" only when needed
- Use `server actions` for form mutations
- Error handling: always use try/catch with typed errors
- API responses: `{ data, error, message }` format
- Use zod for all input validation

### Testing
- Unit tests required for all utility functions
- Integration tests for API routes
- E2E tests for critical user flows
- Minimum coverage: 80%
- Test file naming: `*.test.ts` or `*.test.tsx`

## Commands
- `pnpm dev` - Start dev server
- `pnpm build` - Production build
- `pnpm test` - Run all tests
- `pnpm test:e2e` - Run E2E tests
- `pnpm lint` - ESLint check
- `pnpm db:push` - Push schema to database
- `pnpm db:seed` - Seed database

## Important Notes
- NEVER expose API keys in client-side code
- Always use environment variables for secrets
- Run `pnpm lint` before committing
- PR descriptions must include "Test Plan" section
```

<Callout type="warning" title="Kích thước CLAUDE.md">
CLAUDE.md được load vào context mỗi lần Claude Code khởi chạy, tiêu tốn tokens. Giữ file ngắn gọn, tập trung vào thông tin Claude Code cần để làm việc hiệu quả. Tránh copy toàn bộ documentation vào đây. Lý tưởng là dưới 500 dòng.
</Callout>

### CLAUDE.md cấp thư mục

Bạn có thể tạo CLAUDE.md chuyên biệt cho từng thư mục:

```markdown
<!-- src/components/CLAUDE.md -->

# Component Guidelines

## Khi tạo component mới:
1. Tạo thư mục riêng cho component
2. Export qua barrel file (index.ts)
3. Sử dụng CSS Modules cho styling
4. Thêm `data-testid` cho testing
5. Viết Storybook story nếu là UI component

## Accessibility
- Mọi interactive element phải có aria-label
- Sử dụng semantic HTML elements
- Đảm bảo keyboard navigation hoạt động
- Color contrast ratio tối thiểu 4.5:1
```

## Environment Variables

Claude Code hỗ trợ nhiều biến môi trường để cấu hình:

```bash
# Authentication
export ANTHROPIC_API_KEY="sk-ant-..."

# Model selection
export CLAUDE_MODEL="claude-sonnet-4-6"

# Behavior
export CLAUDE_CODE_MAX_TURNS=50
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1

# Proxy (cho corporate networks)
export HTTP_PROXY="http://proxy.company.com:8080"
export HTTPS_PROXY="http://proxy.company.com:8080"

# Custom API endpoint (cho Enterprise)
export ANTHROPIC_BASE_URL="https://claude.company.com/api"
```

<Callout type="info" title="Dotenv support">
Claude Code tự động đọc file `.env` tại project root nếu có. Tuy nhiên, không nên đặt `ANTHROPIC_API_KEY` trong `.env` của dự án vì có thể bị commit. Đặt trong profile shell (`~/.zshrc` hoặc `~/.bashrc`) an toàn hơn.
</Callout>

## Tích hợp IDE

### VS Code Extension

Claude Code có extension chính thức cho VS Code, cho phép sử dụng Claude Code trực tiếp trong editor:

```json
// .vscode/settings.json
{
  "claudeCode.enable": true,
  "claudeCode.model": "claude-sonnet-4-6",
  "claudeCode.terminalProfile": "Claude Code",
  "claudeCode.showInlineCompletions": true
}
```

**Cách cài đặt:**

1. Mở VS Code
2. Vào Extensions (Ctrl+Shift+X)
3. Tìm "Claude Code"
4. Cài đặt extension của Anthropic
5. Mở terminal panel - Claude Code xuất hiện như một terminal profile

**Tính năng trong VS Code:**
- Mở Claude Code trong integrated terminal
- Gửi file/selection đến Claude Code từ context menu
- Xem diff trước khi apply changes
- Nhận inline suggestions

### JetBrains Plugin

Claude Code cũng hỗ trợ các IDE của JetBrains (IntelliJ, WebStorm, PyCharm):

1. Mở Settings > Plugins
2. Tìm "Claude Code" trong Marketplace
3. Cài đặt và restart IDE
4. Claude Code xuất hiện trong Tool Windows

## Cấu hình cho Team

Trong môi trường team, bạn nên chuẩn hóa cấu hình qua các file được version control:

```
my-project/
├── .claude/
│   ├── settings.json      # Shared project settings
│   ├── commands/           # Shared slash commands
│   │   ├── deploy.md
│   │   └── review.md
│   └── skills/             # Shared skills
│       └── create-api.md
├── CLAUDE.md               # Project context
└── .gitignore              # Đảm bảo KHÔNG ignore .claude/
```

```gitignore
# .gitignore - KHÔNG ignore cấu hình Claude Code
# Nhưng ignore local overrides
.claude/settings.local.json
```

<Callout type="tip" title="Onboarding team members">
Khi có CLAUDE.md và `.claude/` cấu hình sẵn trong repo, team members mới chỉ cần clone repo, cài Claude Code, và bắt đầu làm việc. Claude Code sẽ tự động hiểu conventions, tech stack, và workflows của dự án.
</Callout>

## Quản lý Context và Memory

### Compact Mode

Khi phiên làm việc dài, context window có thể đầy. Sử dụng `/compact` để nén:

```bash
# Nén tự động khi context gần đầy
> /compact

# Nén với tóm tắt cụ thể
> /compact Giữ lại context về authentication refactoring
```

### Memory System

Claude Code có hệ thống memory cho phép lưu trữ thông tin xuyên phiên:

```bash
# Trong phiên Claude Code
> Nhớ rằng dự án này sử dụng pnpm, không phải npm

# Claude Code sẽ lưu vào CLAUDE.md hoặc memory system
# Thông tin này sẽ có sẵn trong các phiên sau
```

### Tiếp tục phiên làm việc

```bash
# Tiếp tục phiên gần nhất
claude --continue

# Liệt kê các phiên trước
claude --list-sessions

# Tiếp tục phiên cụ thể
claude --resume <session-id>
```

## Checklist cấu hình cho dự án mới

Khi bắt đầu dự án mới với Claude Code, hãy thực hiện các bước sau:

1. **Tạo CLAUDE.md** tại project root với tech stack, conventions, commands
2. **Tạo `.claude/settings.json`** với permissions và MCP servers phù hợp
3. **Tạo custom commands** cho các tác vụ thường xuyên (deploy, test, review)
4. **Cấu hình hooks** cho auto-format và security checks
5. **Test configuration** bằng cách chạy Claude Code và yêu cầu mô tả dự án

```bash
# Verify cấu hình hoạt động
claude -p "Mô tả tech stack và conventions của dự án này dựa trên CLAUDE.md"
```

<Callout type="info" title="Cập nhật thường xuyên">
CLAUDE.md nên được cập nhật khi dự án phát triển: thêm conventions mới, cập nhật commands, ghi chú các quyết định kiến trúc quan trọng. Xem đây là "living documentation" cho AI assistant của bạn.
</Callout>
