# MCP Servers - Mở rộng khả năng Claude Code

## Model Context Protocol (MCP) là gì?

Model Context Protocol (MCP) là một **giao thức mở** do Anthropic phát triển, cho phép các ứng dụng AI kết nối với các nguồn dữ liệu và công cụ bên ngoài một cách chuẩn hóa. Trong Claude Code, MCP servers hoạt động như các **plugin mở rộng**, bổ sung thêm tools và capabilities mà Claude Code có thể sử dụng.

<Callout type="info" title="Ý nghĩa của MCP">
Nếu Claude Code built-in tools giống như bộ công cụ cơ bản (đọc file, chỉnh sửa, chạy lệnh), thì MCP servers là cách bạn thêm công cụ chuyên dụng: truy vấn database, tương tác với API, quản lý infrastructure, v.v.
</Callout>

## Kiến trúc MCP

MCP hoạt động theo mô hình client-server. Claude Code đóng vai trò MCP client, kết nối đến một hoặc nhiều MCP servers, mỗi server cung cấp một tập tools riêng.

### Giao tiếp giữa Client và Server

MCP sử dụng **JSON-RPC 2.0** qua stdio hoặc HTTP (SSE) để giao tiếp:

```
Client (Claude Code)          Server (MCP Server)
       |                              |
       |-- initialize -->             |
       |<-- capabilities --           |
       |                              |
       |-- tools/list -->             |
       |<-- tool definitions --       |
       |                              |
       |-- tools/call (query) -->     |
       |<-- result --                 |
```

## Cài đặt MCP Servers

### Cấu hình trong Claude Code

MCP servers được cấu hình trong file `.claude/settings.json` (cấp dự án) hoặc `~/.claude/settings.json` (cấp user):

```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "postgresql://user:pass@localhost:5432/mydb"
      }
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "ghp_..."
      }
    },
    "filesystem": {
      "command": "npx",
      "args": [
        "-y", "@modelcontextprotocol/server-filesystem",
        "/path/to/allowed/directory"
      ]
    }
  }
}
```

### Ví dụ sử dụng

Sau khi cấu hình, Claude Code tự động có thể sử dụng tools từ MCP servers:

```bash
# Trong phiên Claude Code, sau khi cấu hình postgres MCP server:

> Liệt kê tất cả users đã đăng ký trong 7 ngày qua
# Claude Code sẽ sử dụng MCP tool "query" để chạy SQL:
# SELECT * FROM users WHERE created_at > NOW() - INTERVAL '7 days'

> Tạo GitHub issue cho bug login không hoạt động trên Safari
# Claude Code sẽ dùng MCP tool "create_issue" từ GitHub server

> Gửi tin nhắn vào channel #dev-updates trên Slack rằng feature X đã deploy
# Claude Code dùng MCP tool "send_message" từ Slack server
```

<Callout type="warning" title="Bảo mật MCP Servers">
MCP servers có thể truy cập dữ liệu nhạy cảm (database, API tokens). Hãy: (1) Không commit API keys vào repo - sử dụng environment variables, (2) Giới hạn quyền truy cập tối thiểu cần thiết, (3) Chỉ cài đặt MCP servers từ nguồn đáng tin cậy, (4) Review tool calls trước khi approve.
</Callout>

## Viết MCP Server riêng

Khi các MCP servers có sẵn không đáp ứng nhu cầu, bạn có thể viết server riêng. MCP SDK hỗ trợ TypeScript, Python, và các ngôn ngữ khác.

### Cấu trúc MCP Server cơ bản (TypeScript)

```typescript
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { z } from "zod";

// Tạo server instance
const server = new McpServer({
  name: "my-custom-server",
  version: "1.0.0",
});

// Định nghĩa tool: Kiểm tra trạng thái deployment
server.tool(
  "check-deployment",
  "Kiểm tra trạng thái deployment của một service",
  {
    service: z.string().describe("Tên service cần kiểm tra"),
    environment: z
      .enum(["staging", "production"])
      .describe("Môi trường cần kiểm tra"),
  },
  async ({ service, environment }) => {
    // Logic kiểm tra deployment
    const status = await checkDeploymentStatus(service, environment);

    return {
      content: [
        {
          type: "text",
          text: JSON.stringify(status, null, 2),
        },
      ],
    };
  }
);

// Định nghĩa tool: Deploy service
server.tool(
  "deploy-service",
  "Deploy một service lên environment chỉ định",
  {
    service: z.string().describe("Tên service"),
    environment: z.enum(["staging", "production"]),
    version: z.string().describe("Version tag cần deploy"),
  },
  async ({ service, environment, version }) => {
    const result = await deployService(service, environment, version);

    return {
      content: [
        {
          type: "text",
          text: `Deployed ${service}@${version} to ${environment}. Status: ${result.status}`,
        },
      ],
    };
  }
);

// Khởi chạy server
const transport = new StdioServerTransport();
await server.connect(transport);
```

## MCP Server với Python

Nếu bạn quen Python hơn TypeScript, MCP SDK cũng hỗ trợ Python:

```python
# server.py
from mcp.server import Server
from mcp.server.stdio import stdio_server
import mcp.types as types

server = Server("my-python-server")

@server.list_tools()
async def list_tools() -> list[types.Tool]:
    return [
        types.Tool(
            name="analyze-logs",
            description="Phân tích log files và tìm patterns",
            inputSchema={
                "type": "object",
                "properties": {
                    "log_path": {
                        "type": "string",
                        "description": "Đường dẫn đến file log"
                    },
                    "pattern": {
                        "type": "string",
                        "description": "Pattern cần tìm (regex)"
                    }
                },
                "required": ["log_path"]
            }
        )
    ]

@server.call_tool()
async def call_tool(
    name: str,
    arguments: dict
) -> list[types.TextContent]:
    if name == "analyze-logs":
        result = analyze_log_file(
            arguments["log_path"],
            arguments.get("pattern")
        )
        return [types.TextContent(type="text", text=result)]

async def main():
    async with stdio_server() as (read, write):
        await server.run(read, write)

if __name__ == "__main__":
    import asyncio
    asyncio.run(main())
```

## Best Practices

1. **Principle of least privilege** - Chỉ cấp quyền tối thiểu cần thiết cho mỗi MCP server
2. **Error handling** - MCP server phải xử lý lỗi gracefully và trả về messages rõ ràng
3. **Input validation** - Sử dụng Zod hoặc tương đương để validate tất cả input
4. **Idempotency** - Tools nên idempotent khi có thể, tránh side effects không mong muốn
5. **Documentation** - Viết descriptions rõ ràng cho mỗi tool để Claude Code hiểu khi nào nên sử dụng
6. **Rate limiting** - Implement rate limiting cho các tools gọi external APIs
