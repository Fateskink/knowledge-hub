# JavaScript Hiện đại (ES6+)

JavaScript đã thay đổi rất nhiều kể từ phiên bản ES6 (ECMAScript 2015). Những tính năng mới giúp code ngắn gọn, dễ đọc và mạnh mẽ hơn. Bài viết này sẽ giới thiệu những tính năng quan trọng nhất mà mọi lập trình viên web cần biết.

## Khai báo biến: var, let và const

ES6 giới thiệu `let` và `const` để thay thế `var`, giúp quản lý phạm vi (scope) biến tốt hơn.

<ComparisonTable headers={["Đặc điểm", "var", "let", "const"]} rows={[["Phạm vi (scope)", "Function scope", "Block scope", "Block scope"], ["Hoisting", "Có (giá trị undefined)", "Có (nhưng không truy cập được)", "Có (nhưng không truy cập được)"], ["Gán lại giá trị", "Có thể", "Có thể", "Không thể"], ["Khai báo lại", "Có thể", "Không thể", "Không thể"], ["Khi nào dùng", "Không nên dùng nữa", "Khi cần thay đổi giá trị", "Mặc định nên dùng"]]} />

```javascript
// var - phạm vi function, có thể gây lỗi bất ngờ
var x = 10;
if (true) {
  var x = 20;  // Ghi đè biến x ban đầu!
}
console.log(x); // 20 - kết quả bất ngờ

// let - phạm vi block, an toàn hơn
let y = 10;
if (true) {
  let y = 20;  // Biến y mới, chỉ tồn tại trong block
}
console.log(y); // 10 - đúng như mong đợi

// const - không thể gán lại, nhưng object/array vẫn có thể thay đổi nội dung
const user = { name: "An", age: 25 };
user.age = 26;           // OK - thay đổi thuộc tính
// user = { name: "Binh" }; // LỖI - không thể gán lại
```

<Callout type="tip">Quy tắc chung: Luôn dùng `const` làm mặc định. Chỉ dùng `let` khi bạn cần thay đổi giá trị của biến. Không bao giờ dùng `var` trong code mới.</Callout>

## Arrow Functions

Arrow functions cung cấp cú pháp ngắn gọn hơn cho việc viết hàm và xử lý `this` khác với hàm truyền thống.

```javascript
// Hàm truyền thống
function tinh_tong(a, b) {
  return a + b;
}

// Arrow function
const tinhTong = (a, b) => a + b;

// Với thân hàm nhiều dòng
const tinhDiemTB = (diem) => {
  const tong = diem.reduce((acc, d) => acc + d, 0);
  return tong / diem.length;
};

// Làm callback
const soLe = [1, 2, 3, 4, 5, 6].filter(n => n % 2 !== 0);
console.log(soLe); // [1, 3, 5]

// Map và transform dữ liệu
const users = [
  { ten: "An", tuoi: 25 },
  { ten: "Bình", tuoi: 30 },
  { ten: "Chi", tuoi: 22 },
];

const tenUsers = users.map(u => u.ten);
console.log(tenUsers); // ["An", "Bình", "Chi"]

const nguoiLon = users.filter(u => u.tuoi >= 25);
console.log(nguoiLon); // [{ ten: "An", tuoi: 25 }, { ten: "Bình", tuoi: 30 }]
```

<Callout type="warning">Arrow functions không có `this` riêng. Chúng kế thừa `this` từ scope cha. Vì vậy, không nên dùng arrow function làm method của object khi cần truy cập `this`.</Callout>

## Destructuring

Destructuring cho phép bạn trích xuất giá trị từ object hoặc array một cách ngắn gọn.

```javascript
// Object destructuring
const sinhVien = {
  hoTen: "Nguyễn Văn An",
  tuoi: 22,
  truong: "Bách Khoa",
  diem: { toan: 9, ly: 8, hoa: 7.5 }
};

const { hoTen, tuoi, truong } = sinhVien;
console.log(hoTen); // "Nguyễn Văn An"

// Đổi tên biến
const { hoTen: ten, tuoi: age } = sinhVien;
console.log(ten); // "Nguyễn Văn An"

// Giá trị mặc định
const { lop = "Chưa xác định" } = sinhVien;
console.log(lop); // "Chưa xác định"

// Nested destructuring
const { diem: { toan, ly } } = sinhVien;
console.log(toan); // 9

// Array destructuring
const mauSac = ["đỏ", "xanh", "vàng", "tím"];
const [mau1, mau2, ...mauConLai] = mauSac;
console.log(mau1);       // "đỏ"
console.log(mauConLai);  // ["vàng", "tím"]

// Hoán đổi giá trị
let a = 1, b = 2;
[a, b] = [b, a];
console.log(a, b); // 2, 1

// Destructuring trong tham số hàm
const hienThiUser = ({ hoTen, tuoi, truong = "N/A" }) => {
  console.log(`${hoTen}, ${tuoi} tuổi, học tại ${truong}`);
};
hienThiUser(sinhVien);
```

## Template Literals

Template literals sử dụng backtick (\`) để tạo chuỗi có nhiều dòng và nhúng biểu thức.

```javascript
const ten = "An";
const tuoi = 25;

// Trước ES6
var loiChao = "Xin chào, " + ten + "! Bạn " + tuoi + " tuổi.";

// ES6+ Template Literals
const loiChaoMoi = `Xin chào, ${ten}! Bạn ${tuoi} tuổi.`;

// Nhiều dòng
const html = `
  <div class="card">
    <h2>${ten}</h2>
    <p>Tuổi: ${tuoi}</p>
    <p>Năm sinh: ${2026 - tuoi}</p>
  </div>
`;

// Tagged template literals
const highlight = (strings, ...values) => {
  return strings.reduce((result, str, i) => {
    return `${result}${str}<mark>${values[i] || ""}</mark>`;
  }, "");
};

const ketQua = highlight`Tên: ${ten}, Tuổi: ${tuoi}`;
```

## Spread và Rest Operators

Toán tử `...` có thể dùng để trải (spread) hoặc gom (rest) các phần tử.

```javascript
// Spread - trải phần tử
const mang1 = [1, 2, 3];
const mang2 = [4, 5, 6];
const tatCa = [...mang1, ...mang2]; // [1, 2, 3, 4, 5, 6]

// Sao chép object
const userGoc = { ten: "An", tuoi: 25 };
const userMoi = { ...userGoc, email: "an@example.com" };
// { ten: "An", tuoi: 25, email: "an@example.com" }

// Rest - gom các tham số còn lại
const tinhTongTatCa = (...soLieu) => {
  return soLieu.reduce((tong, so) => tong + so, 0);
};
console.log(tinhTongTatCa(1, 2, 3, 4, 5)); // 15
```

## Promises

Promises đại diện cho một giá trị có thể có trong tương lai, giúp xử lý các tác vụ bất đồng bộ (asynchronous).

```javascript
// Tạo một Promise
const layDuLieu = (url) => {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (url) {
        resolve({ data: "Dữ liệu từ " + url, status: 200 });
      } else {
        reject(new Error("URL không hợp lệ"));
      }
    }, 1000);
  });
};

// Sử dụng Promise với then/catch
layDuLieu("https://api.example.com/users")
  .then(response => {
    console.log(response.data);
    return layDuLieu("https://api.example.com/posts");
  })
  .then(response => console.log(response.data))
  .catch(error => console.error("Lỗi:", error.message))
  .finally(() => console.log("Hoàn tất"));
```

## Async/Await

Async/await là cú pháp để làm việc với Promises, giúp code bất đồng bộ trở nên dễ đọc như code đồng bộ.

```javascript
// Async function
const layThongTinUser = async (userId) => {
  try {
    const response = await fetch(`https://api.example.com/users/${userId}`);

    if (!response.ok) {
      throw new Error(`HTTP error! Status: ${response.status}`);
    }

    const user = await response.json();
    console.log(`User: ${user.name}`);
    return user;
  } catch (error) {
    console.error("Không thể lấy thông tin user:", error.message);
    throw error;
  }
};

// Chạy nhiều tác vụ đồng thời
const layTatCaDuLieu = async () => {
  try {
    const [users, posts, comments] = await Promise.all([
      fetch("/api/users").then(r => r.json()),
      fetch("/api/posts").then(r => r.json()),
      fetch("/api/comments").then(r => r.json()),
    ]);

    console.log(`${users.length} users, ${posts.length} posts`);
  } catch (error) {
    console.error("Có lỗi khi lấy dữ liệu:", error);
  }
};
```

<Callout type="info">Luôn dùng try/catch với async/await để xử lý lỗi. Nếu không, lỗi sẽ bị nuốt âm thầm (silently swallowed) và khó debug.</Callout>

## ES Modules

Modules giúp bạn chia code thành các file riêng biệt, dễ quản lý và tái sử dụng.

```javascript
// math.js - Export
export const cong = (a, b) => a + b;
export const tru = (a, b) => a - b;

export default class MayTinh {
  cong(a, b) { return a + b; }
  nhan(a, b) { return a * b; }
}

// app.js - Import
import MayTinh, { cong, tru } from "./math.js";

console.log(cong(5, 3));    // 8
console.log(tru(10, 4));    // 6

const mt = new MayTinh();
console.log(mt.nhan(3, 7)); // 21

// Dynamic import - tải module khi cần
const loadChart = async () => {
  const { Chart } = await import("./chart.js");
  const chart = new Chart("#my-chart");
  chart.render();
};
```

## Optional Chaining và Nullish Coalescing

Hai tính năng này giúp xử lý giá trị null/undefined một cách an toàn.

```javascript
const user = {
  ten: "An",
  diaChi: {
    thanhPho: "Hà Nội"
  }
};

// Optional chaining (?.)
console.log(user.diaChi?.thanhPho);    // "Hà Nội"
console.log(user.diaChi?.quan);         // undefined (không lỗi)
console.log(user.congTy?.ten);          // undefined (không lỗi)

// Nullish coalescing (??)
const port = null ?? 3000;             // 3000
const host = "" ?? "localhost";        // "" (chuỗi rỗng không phải null)
const timeout = 0 ?? 5000;            // 0 (số 0 không phải null)

// Kết hợp cả hai
const tenTP = user.diaChi?.thanhPho ?? "Chưa xác định";
console.log(tenTP); // "Hà Nội"
```

## Kết luận

JavaScript hiện đại với ES6+ mang đến nhiều tính năng giúp code ngắn gọn, an toàn và dễ bảo trì hơn. Những tính năng như destructuring, async/await và modules đã trở thành tiêu chuẩn trong phát triển web hiện đại.

Bước tiếp theo của bạn là thực hành các tính năng này trong dự án thực tế. Hãy bắt đầu với một dự án nhỏ và dần dần áp dụng từng tính năng đã học.
