# RackNerd VPS: Hướng Dẫn Triển Khai Dự Án Từ A Đến Z

RackNerd là một trong những lựa chọn VPS giá rẻ nhất hiện nay, cho phép bạn sở hữu một server riêng với giá chưa đến 1 đô la mỗi tháng. ## RackNerd Là Gì?

RackNerd là nhà cung cấp dịch vụ VPS (Virtual Private Server) có trụ sở tại California, Hoa Kỳ. Đây là một IaaS (Infrastructure as a Service) provider chuyên cung cấp VPS giá rẻ với hiệu năng ổn định, phục vụ cả người dùng cá nhân lẫn doanh nghiệp nhỏ.

**Những điểm nổi bật của RackNerd:**

- **Hạ tầng rộng lớn:** 21 datacenter tại 20 địa điểm khác nhau trên toàn cầu, bao gồm Mỹ, Châu Âu và Châu Á. Bạn có thể chọn datacenter gần nhất với đối tượng người dùng của mình.

- **Được công nhận:** RackNerd đã lọt vào danh sách Inc. 5000 và Inc. Regionals Pacific - chứng minh tốc độ tăng trưởng ấn tượng và uy tín trong ngành.
- **Deal huyền thoại:** Nổi tiếng với các đợt khuyến mãi Black Friday, New Year với mức giá cực kỳ hấp dẫn, thường rẻ hơn 50-70% so với giá thông thường.

## Cấu Hình Server Ban Đầu

Sau khi có VPS, bước đầu tiên là bảo mật và cấu hình cơ bản. Đây là các bước thiết yếu:

```bash
# SSH vào server (thay YOUR_IP và YOUR_PORT bằng thông tin trong email)
ssh root@YOUR_IP -p YOUR_PORT

# Đổi mật khẩu root
passwd

# Cập nhật hệ thống
apt update && apt upgrade -y

# Tạo user mới (không nên dùng root cho công việc hàng ngày)
adduser deploy
usermod -aG sudo deploy

# Chuyển sang user mới
su - deploy
```

Tiếp theo, thiết lập SSH key để đăng nhập an toàn hơn:

```bash
# Trên máy LOCAL của bạn (không phải server)
ssh-keygen -t ed25519 -C "your_email@example.com"
ssh-copy-id deploy@YOUR_IP -p YOUR_PORT
```

Sau khi xác nhận đăng nhập bằng SSH key thành công, tắt đăng nhập bằng mật khẩu:

```bash
# Trên server, chỉnh sửa cấu hình SSH
sudo nano /etc/ssh/sshd_config
# Tìm và đổi: PasswordAuthentication no
sudo systemctl restart sshd
```

Cuối cùng, cài đặt và cấu hình firewall:

```bash
sudo apt install ufw -y
sudo ufw allow OpenSSH
sudo ufw allow 80
sudo ufw allow 443
sudo ufw enable
```

## Deploy Ứng Dụng Node.js / Next.js

### Cài Đặt Node.js

Cài Node.js 20.x (LTS) từ NodeSource:

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v  # Xác nhận phiên bản
npm -v
```

### Clone Code và Cài Dependencies

```bash
cd /home/deploy
git clone https://github.com/your-username/your-repo.git
cd your-repo
npm install
npm run build  # Bắt buộc cho Next.js production
```

### PM2 - Quản Lý Tiến Trình

PM2 giúp ứng dụng Node.js chạy liên tục, tự khởi động lại khi crash hoặc khi server reboot:

```bash
sudo npm install -g pm2

# Khởi chạy ứng dụng
pm2 start npm --name "my-app" -- start

# Cấu hình tự khởi động cùng hệ thống
pm2 startup systemd
pm2 save

# Một số lệnh hữu ích
pm2 list          # Danh sách tiến trình
pm2 logs my-app   # Xem log
pm2 restart my-app # Khởi động lại
pm2 monit         # Monitor realtime
```

### Nginx Reverse Proxy

Cài đặt Nginx để chuyển tiếp request từ cổng 80 đến ứng dụng Node.js:

```bash
sudo apt install nginx -y
sudo nano /etc/nginx/sites-available/my-app
```

Nội dung cấu hình:

```nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

Kích hoạt cấu hình:

```bash
sudo ln -s /etc/nginx/sites-available/my-app /etc/nginx/sites-enabled/
sudo nginx -t        # Kiểm tra cú pháp
sudo systemctl restart nginx
```

### SSL Với Let's Encrypt

Cài chứng chỉ SSL miễn phí để bật HTTPS:

```bash
sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
```

Certbot sẽ tự động cấu hình Nginx để chuyển hướng HTTP sang HTTPS và tự gia hạn chứng chỉ.

## Deploy Bằng Docker

Nếu bạn muốn cách tiếp cận hiện đại và dễ quản lý hơn, Docker là lựa chọn tuyệt vời:

```bash
# Cài Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker deploy
newgrp docker  # Áp dụng group mới ngay lập tức

# Cài Docker Compose plugin
sudo apt install docker-compose-plugin -y

# Kiểm tra
docker --version
docker compose version
```

## Deploy Bằng Docker Compose (Ví Dụ Thực Tế)

Dưới đây là file `docker-compose.yml` hoàn chỉnh cho stack Next.js + PostgreSQL + Nginx:

```yaml
version: '3.8'
services:
  app:
    build: .
    restart: always
    ports:
      - "3000:3000"
    environment:
      - DATABASE_URL=postgresql://user:pass@db:5432/mydb
      - NODE_ENV=production
    depends_on:
      - db

  db:
    image: postgres:16
    restart: always
    volumes:
      - pgdata:/var/lib/postgresql/data
    environment:
      - POSTGRES_PASSWORD=pass
      - POSTGRES_USER=user
      - POSTGRES_DB=mydb

  nginx:
    image: nginx:alpine
    restart: always
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf
      - ./certbot/conf:/etc/letsencrypt
    depends_on:
      - app

volumes:
  pgdata:
```

Khởi chạy toàn bộ stack:

```bash
docker compose up -d        # Chạy nền
docker compose logs -f      # Xem log
docker compose ps           # Xem trạng thái
docker compose down         # Dừng tất cả
```

<Callout type="tip">Sử dụng file `.env` để quản lý biến môi trường thay vì hardcode trong docker-compose.yml. Thêm `.env` vào `.gitignore` để tránh commit lên repository.</Callout>

## Monitoring và Bảo Trì

Sau khi deploy, bạn cần giám sát server thường xuyên:

- **htop:** Xem tình trạng RAM, CPU realtime. Cài bằng `sudo apt install htop -y`.
- **pm2 monit:** Monitor tiến trình Node.js nếu dùng PM2.
- **docker stats:** Xem tài nguyên các container nếu dùng Docker.
- **Auto-update bảo mật:** Cài `unattended-upgrades` để tự động cập nhật các bản vá bảo mật.

```bash
sudo apt install unattended-upgrades -y
sudo dpkg-reconfigure --priority=low unattended-upgrades
```

- **Backup:** Sử dụng `rsync` để sao lưu dữ liệu về máy local, hoặc tạo snapshot từ panel quản trị SolusVM của RackNerd.

## Mẹo Tiết Kiệm và Tối Ưu

Khi chạy VPS với RAM hạn chế, những mẹo sau sẽ giúp bạn tận dụng tối đa tài nguyên:

**Tạo swap file nếu RAM ít:**

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

**Bật nén gzip trong Nginx** để giảm băng thông:

```nginx
gzip on;
gzip_types text/plain text/css application/json application/javascript text/xml;
gzip_min_length 1000;
```

**Dùng SQLite thay PostgreSQL** cho dự án nhỏ - tiết kiệm đáng kể RAM (PostgreSQL chiếm ~100-200MB RAM ở trạng thái nghỉ).

**Cân nhắc Caddy** thay Nginx nếu bạn muốn auto-SSL đơn giản hơn. Caddy tự động xin và gia hạn chứng chỉ SSL mà không cần cấu hình thêm.
