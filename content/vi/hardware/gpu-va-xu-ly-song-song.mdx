# GPU và Xử lý song song - Sức mạnh đằng sau AI và đồ họa

GPU (Graphics Processing Unit) ban đầu được tạo ra để xử lý đồ họa - render game, video, giao diện người dùng. Nhưng ngày nay, GPU đã trở thành **bộ não của trí tuệ nhân tạo**, chạy các mô hình học sâu với hàng tỷ tham số. Tại sao một chip "vẽ hình" lại trở thành vũ khí bí mật của AI? Câu trả lời nằm ở **xử lý song song**.

## GPU là gì và khác CPU ở đâu?

### CPU: "Tiến sĩ" - ít nhưng giỏi

CPU có **ít nhân** (4-24 nhân cho consumer) nhưng mỗi nhân rất mạnh, xử lý các tác vụ phức tạp, tuần tự một cách nhanh chóng. CPU giỏi việc **ra quyết định**, xử lý logic phức tạp, chuyển nhanh giữa các tác vụ.

### GPU: "Công nhân" - nhiều và làm việc song song

GPU có **hàng nghìn nhân nhỏ** (CUDA cores), mỗi nhân yếu hơn nhân CPU nhưng làm việc đồng loạt. GPU giỏi việc thực hiện **cùng một phép tính trên hàng triệu dữ liệu khác nhau** cùng lúc.

## Kiến trúc GPU

### CUDA Cores (NVIDIA) / Stream Processors (AMD)

Đây là đơn vị xử lý cơ bản của GPU, thực hiện các phép tính số học đơn giản (cộng, nhân, so sánh).

```
Kiến trúc NVIDIA (Ví dụ: RTX 4090):

GPU
├── GPC (Graphics Processing Cluster) x 12
│   ├── TPC (Texture Processing Cluster) x 6
│   │   ├── SM (Streaming Multiprocessor) x 2
│   │   │   ├── CUDA Cores: 128
│   │   │   ├── Tensor Cores: 4
│   │   │   ├── RT Cores: 1
│   │   │   ├── Register File: 256 KB
│   │   │   └── Shared Memory: 128 KB
│   │   │
│   │   └── SM ...
│   └── TPC ...
└── GPC ...

Tổng: 16,384 CUDA Cores, 512 Tensor Cores, 128 RT Cores
```

### Tensor Cores

**Tensor Cores** là đơn vị tính toán chuyên dụng cho phép **nhân ma trận** (matrix multiplication) - phép toán cốt lõi của AI/ML. Một Tensor Core có thể thực hiện phép nhân ma trận 4x4 trong **1 chu kỳ clock**, trong khi CUDA Cores cần hàng trăm chu kỳ.

```
Phép nhân ma trận 4x4:

CUDA Cores: Cần 64 phép nhân + 48 phép cộng = 112 phép tính
Tensor Core: Thực hiện TOÀN BỘ trong 1 chu kỳ!

Tốc độ AI training với Tensor Cores nhanh hơn 5-10 lần
so với chỉ dùng CUDA Cores.
```

### RT Cores

**RT Cores** (Ray Tracing Cores) chuyên xử lý **dò vết tia sáng** (ray tracing) - tính toán đường đi của tia sáng để tạo hình ảnh 3D chân thực với bóng, phản chiếu, khúc xạ ánh sáng.

### VRAM (Video RAM)

GPU có bộ nhớ riêng gọi là **VRAM**, tối ưu cho truy cập song song băng thông cao:

```
VRAM so với RAM:

RAM hệ thống (DDR5-6400):
- Băng thông: ~51 GB/s
- Dung lượng: 16-128 GB
- Chia sẻ cho cả hệ thống

VRAM (GDDR6X - RTX 4090):
- Băng thông: ~1,008 GB/s (gấp 20 lần RAM!)
- Dung lượng: 24 GB
- Dành riêng cho GPU

VRAM (HBM3 - H100):
- Băng thông: ~3,350 GB/s (gấp 65 lần RAM!)
- Dung lượng: 80 GB
- Dành cho data center AI
```

<Callout type="warning">VRAM là yếu tố giới hạn quan trọng nhất khi chạy AI. Mô hình LLM (như GPT) cần lưu tất cả tham số trong VRAM. Mô hình 70B tham số (FP16) cần khoảng 140 GB VRAM - vượt quá mọi GPU consumer. Đây là lý do AI training cần nhiều GPU đắt tiền.</Callout>

## Tại sao GPU quan trọng cho AI/ML?

### AI là phép nhân ma trận khổng lồ

Mạng nơ-ron (neural network) về cơ bản là **hàng loạt phép nhân ma trận**:

```python
# Forward pass của 1 lớp neural network:
# output = activation(input @ weights + bias)

import numpy as np

# input: 1000 mẫu, 512 features
input_data = np.random.randn(1000, 512)

# weights: 512 x 256
weights = np.random.randn(512, 256)

# Phép nhân ma trận: 1000 x 512 nhân 512 x 256
# = 1000 x 512 x 256 = 131 TRIỆU phép nhân!
output = input_data @ weights

# Mô hình GPT-4 có 1.8 NGHÌN TỶ tham số
# Mỗi token cần hàng tỷ phép nhân ma trận
# -> Chỉ GPU mới đủ nhanh
```

### GPU xử lý song song hoàn hảo cho AI

### Các framework AI trên GPU

```python
# PyTorch - Chuyển dữ liệu và mô hình lên GPU
import torch

# Kiểm tra GPU
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print(f"Đang dùng: {device}")

# Tạo tensor trên GPU
x = torch.randn(1000, 512, device=device)
w = torch.randn(512, 256, device=device)

# Phép nhân ma trận trên GPU - nhanh hơn CPU 10-100 lần
result = torch.matmul(x, w)
print(f"Kết quả: {result.shape}")  # torch.Size([1000, 256])
```

```python
# So sánh tốc độ CPU vs GPU
import time

size = 10000

# CPU
x_cpu = torch.randn(size, size)
start = time.time()
result_cpu = torch.matmul(x_cpu, x_cpu)
cpu_time = time.time() - start

# GPU
x_gpu = torch.randn(size, size, device='cuda')
torch.cuda.synchronize()
start = time.time()
result_gpu = torch.matmul(x_gpu, x_gpu)
torch.cuda.synchronize()
gpu_time = time.time() - start

print(f"CPU: {cpu_time:.3f}s")
print(f"GPU: {gpu_time:.3f}s")
print(f"GPU nhanh hơn: {cpu_time/gpu_time:.1f}x")
# Thường gặp: GPU nhanh hơn 20-100 lần!
```

## Lập trình GPU cơ bản

### Mô hình CUDA

CUDA cho phép viết code chạy trên GPU. Ý tưởng chính: viết một hàm (**kernel**) chạy trên **hàng nghìn thread song song**.

```c
// Ví dụ CUDA đơn giản: Cộng 2 mảng

// Kernel chạy trên GPU
__global__ void add_vectors(float *a, float *b, float *c, int n) {
    // Mỗi thread xử lý 1 phần tử
    int i = blockIdx.x * blockDim.x + threadIdx.x;
    if (i < n) {
        c[i] = a[i] + b[i];
    }
}

// Gọi từ CPU
int main() {
    int n = 1000000;  // 1 triệu phần tử

    // Cấp phát bộ nhớ trên GPU
    float *d_a, *d_b, *d_c;
    cudaMalloc(&d_a, n * sizeof(float));
    cudaMalloc(&d_b, n * sizeof(float));
    cudaMalloc(&d_c, n * sizeof(float));

    // Chạy 1000 block x 1024 thread = 1,024,000 thread song song!
    add_vectors<<<1000, 1024>>>(d_a, d_b, d_c, n);

    cudaFree(d_a); cudaFree(d_b); cudaFree(d_c);
    return 0;
}
```

<Callout type="tip">Bạn không cần học CUDA trực tiếp để làm AI. Các framework như PyTorch, TensorFlow đã đóng gói CUDA bên trong. Chỉ cần gọi `.to('cuda')` và framework sẽ tự động tối ưu việc chạy trên GPU.</Callout>

## Xu hướng tương lai

- **GPU cho AI ngày càng mạnh**: NVIDIA Blackwell (B100, B200) với hiệu suất AI gấp nhiều lần thế hệ trước.
- **Chiplet GPU**: AMD dùng kiến trúc chiplet (ghép nhiều chip nhỏ) để tăng kích thước GPU mà không tăng chi phí.
- **AI on-device**: NPU (Neural Processing Unit) tích hợp trong CPU cho AI trên điện thoại, laptop mà không cần cloud.
- **Quantum computing**: Có thể thay thế GPU cho một số bài toán trong tương lai xa.

## Tóm tắt

GPU đã tiến hóa từ chip xử lý đồ họa thành **bộ xử lý song song đa năng**, là động lực chính của cuộc cách mạng AI. Với hàng nghìn nhân xử lý, băng thông bộ nhớ khổng lồ, và Tensor Cores chuyên dụng, GPU có thể thực hiện hàng nghìn tỷ phép tính mỗi giây - điều mà CPU không thể làm được. Hiểu về GPU giúp bạn hiểu tại sao AI phát triển nhanh đến vậy, và tại sao NVIDIA trở thành một trong những công ty giá trị nhất thế giới.
