# Modern JavaScript (ES6+)

JavaScript has changed dramatically since ES6 (ECMAScript 2015). The new features make code shorter, more readable, and more powerful. This article introduces the most important features that every web developer should know.

## Variable Declarations: var, let, and const

ES6 introduced `let` and `const` to replace `var`, providing better scope management.

<ComparisonTable headers={["Feature", "var", "let", "const"]} rows={[["Scope", "Function scope", "Block scope", "Block scope"], ["Hoisting", "Yes (value is undefined)", "Yes (but not accessible)", "Yes (but not accessible)"], ["Reassignment", "Allowed", "Allowed", "Not allowed"], ["Redeclaration", "Allowed", "Not allowed", "Not allowed"], ["When to use", "Avoid in new code", "When value changes", "Default choice"]]} />

```javascript
// var - function scoped, can cause unexpected bugs
var x = 10;
if (true) {
  var x = 20;  // Overwrites the original x!
}
console.log(x); // 20 - unexpected result

// let - block scoped, much safer
let y = 10;
if (true) {
  let y = 20;  // New y, exists only within this block
}
console.log(y); // 10 - as expected

// const - cannot be reassigned, but object/array contents can be modified
const user = { name: "Alice", age: 25 };
user.age = 26;              // OK - modifying a property
// user = { name: "Bob" };  // ERROR - cannot reassign
```

<Callout type="tip">Rule of thumb: Always use `const` by default. Only use `let` when you need to reassign a variable. Never use `var` in new code.</Callout>

## Arrow Functions

Arrow functions provide a more concise syntax for writing functions and handle `this` differently from traditional functions.

```javascript
// Traditional function
function add(a, b) {
  return a + b;
}

// Arrow function
const add = (a, b) => a + b;

// With multi-line body
const calculateAverage = (scores) => {
  const total = scores.reduce((acc, s) => acc + s, 0);
  return total / scores.length;
};

// As callbacks
const oddNumbers = [1, 2, 3, 4, 5, 6].filter(n => n % 2 !== 0);
console.log(oddNumbers); // [1, 3, 5]

// Map and transform data
const users = [
  { name: "Alice", age: 25 },
  { name: "Bob", age: 30 },
  { name: "Charlie", age: 22 },
];

const names = users.map(u => u.name);
console.log(names); // ["Alice", "Bob", "Charlie"]

const adults = users.filter(u => u.age >= 25);
console.log(adults); // [{ name: "Alice", age: 25 }, { name: "Bob", age: 30 }]
```

<Callout type="warning">Arrow functions do not have their own `this`. They inherit `this` from the enclosing scope. Therefore, you should not use arrow functions as object methods when you need to access `this`.</Callout>

## Destructuring

Destructuring allows you to extract values from objects or arrays in a concise way.

```javascript
// Object destructuring
const student = {
  fullName: "Alice Johnson",
  age: 22,
  university: "MIT",
  grades: { math: 95, physics: 88, chemistry: 92 }
};

const { fullName, age, university } = student;
console.log(fullName); // "Alice Johnson"

// Rename variables
const { fullName: name, age: studentAge } = student;
console.log(name); // "Alice Johnson"

// Default values
const { major = "Undeclared" } = student;
console.log(major); // "Undeclared"

// Nested destructuring
const { grades: { math, physics } } = student;
console.log(math); // 95

// Array destructuring
const colors = ["red", "blue", "yellow", "purple"];
const [first, second, ...rest] = colors;
console.log(first);  // "red"
console.log(rest);   // ["yellow", "purple"]

// Swapping values
let a = 1, b = 2;
[a, b] = [b, a];
console.log(a, b); // 2, 1

// Destructuring in function parameters
const displayUser = ({ fullName, age, university = "N/A" }) => {
  console.log(`${fullName}, age ${age}, studying at ${university}`);
};
displayUser(student);
```

## Template Literals

Template literals use backticks (\`) to create strings with embedded expressions and multi-line support.

```javascript
const name = "Alice";
const age = 25;

// Before ES6
var greeting = "Hello, " + name + "! You are " + age + " years old.";

// ES6+ Template Literals
const newGreeting = `Hello, ${name}! You are ${age} years old.`;

// Multi-line strings
const html = `
  <div class="card">
    <h2>${name}</h2>
    <p>Age: ${age}</p>
    <p>Birth year: ${2026 - age}</p>
  </div>
`;

// Tagged template literals
const highlight = (strings, ...values) => {
  return strings.reduce((result, str, i) => {
    return `${result}${str}<mark>${values[i] || ""}</mark>`;
  }, "");
};

const result = highlight`Name: ${name}, Age: ${age}`;
```

## Spread and Rest Operators

The `...` operator can be used to spread or gather elements.

```javascript
// Spread - expand elements
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];
const combined = [...arr1, ...arr2]; // [1, 2, 3, 4, 5, 6]

// Clone objects
const originalUser = { name: "Alice", age: 25 };
const updatedUser = { ...originalUser, email: "alice@example.com" };
// { name: "Alice", age: 25, email: "alice@example.com" }

// Rest - gather remaining parameters
const sumAll = (...numbers) => {
  return numbers.reduce((total, n) => total + n, 0);
};
console.log(sumAll(1, 2, 3, 4, 5)); // 15
```

## Promises

Promises represent a value that may be available in the future, enabling clean handling of asynchronous operations.

```javascript
// Creating a Promise
const fetchData = (url) => {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (url) {
        resolve({ data: "Data from " + url, status: 200 });
      } else {
        reject(new Error("Invalid URL"));
      }
    }, 1000);
  });
};

// Using Promises with then/catch
fetchData("https://api.example.com/users")
  .then(response => {
    console.log(response.data);
    return fetchData("https://api.example.com/posts");
  })
  .then(response => console.log(response.data))
  .catch(error => console.error("Error:", error.message))
  .finally(() => console.log("Complete"));
```

## Async/Await

Async/await is syntactic sugar for working with Promises, making asynchronous code read like synchronous code.

```javascript
// Async function
const getUserInfo = async (userId) => {
  try {
    const response = await fetch(`https://api.example.com/users/${userId}`);

    if (!response.ok) {
      throw new Error(`HTTP error! Status: ${response.status}`);
    }

    const user = await response.json();
    console.log(`User: ${user.name}`);
    return user;
  } catch (error) {
    console.error("Failed to fetch user:", error.message);
    throw error;
  }
};

// Running multiple tasks concurrently
const fetchAllData = async () => {
  try {
    const [users, posts, comments] = await Promise.all([
      fetch("/api/users").then(r => r.json()),
      fetch("/api/posts").then(r => r.json()),
      fetch("/api/comments").then(r => r.json()),
    ]);

    console.log(`${users.length} users, ${posts.length} posts`);
  } catch (error) {
    console.error("Error fetching data:", error);
  }
};
```

<Callout type="info">Always use try/catch with async/await to handle errors. Without it, errors will be silently swallowed and become very difficult to debug.</Callout>

## ES Modules

Modules let you split your code into separate files, making it easier to manage and reuse.

```javascript
// math.js - Export
export const add = (a, b) => a + b;
export const subtract = (a, b) => a - b;

export default class Calculator {
  add(a, b) { return a + b; }
  multiply(a, b) { return a * b; }
}

// app.js - Import
import Calculator, { add, subtract } from "./math.js";

console.log(add(5, 3));        // 8
console.log(subtract(10, 4));  // 6

const calc = new Calculator();
console.log(calc.multiply(3, 7)); // 21

// Dynamic import - load modules on demand
const loadChart = async () => {
  const { Chart } = await import("./chart.js");
  const chart = new Chart("#my-chart");
  chart.render();
};
```

## Optional Chaining and Nullish Coalescing

These two features help you safely handle null and undefined values.

```javascript
const user = {
  name: "Alice",
  address: {
    city: "New York"
  }
};

// Optional chaining (?.)
console.log(user.address?.city);     // "New York"
console.log(user.address?.zipCode);  // undefined (no error)
console.log(user.company?.name);     // undefined (no error)

// Nullish coalescing (??)
const port = null ?? 3000;           // 3000
const host = "" ?? "localhost";      // "" (empty string is not null)
const timeout = 0 ?? 5000;          // 0 (zero is not null)

// Combining both
const cityName = user.address?.city ?? "Unknown";
console.log(cityName); // "New York"
```

Modern JavaScript with ES6+ brings many features that make code shorter, safer, and easier to maintain. Features like destructuring, async/await, and modules have become standard in modern web development.
