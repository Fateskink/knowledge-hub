## What is Claude Code?

Claude Code is an **agentic coding tool** developed by Anthropic that operates directly in your terminal. Unlike traditional IDE extensions that work alongside your editor, Claude Code is a full-fledged command-line interface that understands your entire codebase, can edit files, run commands, search through code, and manage complex multi-step development tasks autonomously.

Think of it as having a senior developer sitting beside you in the terminal, one who can read your entire project, understand the context, and take action on your behalf.

<Callout type="tip">
Claude Code is not just an autocomplete tool. It is an autonomous agent that can plan, execute, and iterate on complex development tasks across your entire codebase.
</Callout>

### How Claude Code Works

At its core, Claude Code creates an interactive session between you and one of Anthropic's Claude models. When you give it a task, it can read files, search for patterns, edit code, run shell commands, and even create entirely new files, all while maintaining context about your project.

## Installation

Getting started with Claude Code requires Node.js 18 or later. The installation process is straightforward.

### Prerequisites

- **Node.js** version 18 or higher
- **npm** (comes with Node.js)
- An **Anthropic API key** or a **Claude Pro/Team/Enterprise subscription**

### Install via npm

```bash
npm install -g @anthropic-ai/claude-code
```

### Verify the Installation

```bash
claude --version
```

### Authenticate

On first launch, Claude Code will prompt you to authenticate. You have two options:

```bash
# Option 1: Use your Anthropic API key
export ANTHROPIC_API_KEY=sk-ant-...

# Option 2: Launch and follow the OAuth flow
claude
```

<Callout type="info">
If you have a Claude Pro, Team, or Enterprise subscription, you can authenticate via OAuth without needing a separate API key. This is the recommended approach for individual developers.
</Callout>

## Your First Session

Once installed, navigate to your project directory and simply type:

```bash
cd your-project
claude
```

This opens an interactive REPL session. You can now start giving Claude Code instructions in natural language:

```
> Explain the architecture of this project

> Find all API routes that don't have authentication middleware

> Add input validation to the user registration endpoint

> Write tests for the PaymentService class
```

### One-Shot Mode

For quick tasks, you can pass a prompt directly without entering the interactive mode:

```bash
claude -p "What does the main function in src/index.ts do?"
```

This is especially useful for scripting and CI/CD pipelines where you need a single answer or action.

### Print Mode

If you only want Claude to analyze without making changes:

```bash
claude -p "Review this codebase for security vulnerabilities" --no-edit
```

## Key Features

### Codebase Understanding

Claude Code indexes and understands your project structure. It reads files on demand, searches for patterns using grep-like tools, and builds context as it works.

### File Editing

Claude Code can create, modify, and delete files. It shows you exactly what changes it plans to make and asks for confirmation before applying them.

### Shell Command Execution

Need to run tests, install packages, or check git status? Claude Code can execute shell commands and use the output to inform its next steps.

### Multi-Step Reasoning

Complex tasks are broken down into steps. Claude Code plans its approach, executes each step, and adapts based on what it discovers along the way.

<Callout type="tip">

### When to Choose Claude Code

- **Complex refactoring**: Renaming a pattern across 50 files, migrating from one framework to another
- **Code review and analysis**: Understanding unfamiliar codebases, finding security issues
- **Automated workflows**: CI/CD integration, automated code generation from specs
- **Terminal-first workflows**: If you prefer working in the terminal over an IDE

### When Other Tools Might Be Better

- **Real-time autocomplete**: Copilot and Cursor excel at inline suggestions as you type
- **Visual diff review**: IDE-based tools provide richer visual diffs
- **Lightweight edits**: For quick, single-line changes, an inline suggestion might be faster

## Essential Commands

Here are the most commonly used commands and shortcuts within a Claude Code session:

```bash
# Start interactive session
claude

# One-shot question
claude -p "your question here"

# Resume last conversation
claude --continue

# Use a specific model
claude --model claude-sonnet-4-20250514

# Run with a specific permission profile
claude --profile permissive
```

### In-Session Shortcuts

Once inside an interactive session, several slash commands are available:

```
/help          - Show available commands
/clear         - Clear conversation history
/compact       - Summarize and compress context
/model         - Switch the active model
/permissions   - View and manage tool permissions
/memory        - View or edit CLAUDE.md memory files
```

<Callout type="warning">
Claude Code can execute shell commands on your machine. Always review the commands it proposes before approving them, especially when working with production environments or sensitive data.
</Callout>
